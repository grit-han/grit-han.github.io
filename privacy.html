테이크마이머니 개인정보 처리방침

그릿한세상(이하 “운영자”)은 개인정보 보호법 등 관계 법령을 준수하며, 이용자의 개인정보를 안전하게 처리하기 위해 다음과 같이 개인정보 처리방침을 수립·공개합니다.

한눈에 보는 개인정보 처리

  • 테이크마이머니는 개인 굿즈 소장·백업 제공에 필요한 최소한의 정보만 처리합니다.
  • 촬영하거나 선택한 원본 사진은 기기에서 처리하고 서버로 전송하지 않습니다.
  • 서버에는 이용자가 저장한 스티커 결과 이미지와 이름·설명·그룹 정보를 백업합니다.
  • 신체정보·영양 목표를 새로 수집하지 않으며 개인 그룹은 다른 회원에게 공개하지 않습니다.
  • 광고의 맞춤형 여부는 이용자의 동의 상태를 따르며, 동의하지 않아도 앱을 모두 사용할 수 있습니다.
  • 주민등록번호, 결제 카드번호, 주소록, 정밀 위치정보는 수집하지 않습니다.
  • 이용자는 앱에서 콘텐츠를 삭제하거나 계정을 탈퇴할 수 있습니다.

1. 개인정보의 처리 목적, 항목, 법적 근거 및 보유기간

운영자는 다음 목적에 필요한 범위에서 개인정보를 처리합니다.

1) 회원가입·로그인

  • 처리 목적: 본인 식별, 계정 생성, 로그인 유지, 계정 연결
  • 처리 항목: 로그인 제공자, 소셜 로그인 고유 식별자, 이메일 주소(제공되는 경우), 인증 기록(로그인 세션의 IP 주소·기기 정보 포함), 이용약관·개인정보 처리방침·연령 확인 동의 기록(문서 버전과 동의 일시), Apple 연결 해제용 토큰(Apple 로그인 시 암호화 저장)
  • 필수 여부 및 법적 근거: 필수, 서비스 계약의 체결 및 이행. 동의 기록은 동의 사실의 증빙을 위한 법적 의무 준수
  • 보유기간: 회원 탈퇴 시까지

2) 프로필

  • 처리 목적: 서비스 내 이용자 표시
  • 처리 항목: 닉네임, 프로필 이미지, 언어, 시간대
  • 필수 여부 및 법적 근거: 닉네임은 필수, 프로필 이미지는 선택. 서비스 계약의 이행
  • 보유기간: 회원 탈퇴 또는 이용자 삭제 시까지

3) 개인 그룹

  • 처리 목적: 굿즈 분류·저장·계정별 백업·동기화, 접근권한 관리
  • 처리 항목: 그룹 식별자와 이름, 소유자 계정 식별자, 생성 일시, 저장 용량과 구매 권한
  • 필수 여부 및 법적 근거: 해당 기능 이용 시 필수, 서비스 계약의 이행
  • 보유기간: 그룹 또는 계정 삭제 시까지

4) 콘텐츠

  • 처리 목적: 스티커 등록·표시·편집·고정·삭제와 백업·동기화
  • 처리 항목: 결과 이미지(외곽선 없는 공유용 결과 포함), 이름, 설명, 유형, 그룹·소유자 식별자, 생성·고정 일시, 멱등 요청 식별자와 동기화 상태
  • 필수 여부 및 법적 근거: 해당 기능 이용 시 필수, 서비스 계약의 이행 및 이용자의 등록 행위
  • 보유기간: 콘텐츠·그룹 또는 계정 삭제 시까지. 삭제한 DB 자료는 즉시 파기하고 결과 이미지 비동기 삭제는 완료될 때까지 재시도합니다. 회원 탈퇴 시에는 지체 없이 파기합니다

5) 기기 내 저장

  • 처리 목적: 오프라인 소장·편집, 서버 백업·동기화 재시도
  • 처리 항목: 계정별 SQLite 프로필·동의·그룹·콘텐츠 자료, 결과 PNG, 동기화 요청 대기열. 세션 토큰은 기기의 보안 저장소에 저장
  • 필수 여부 및 법적 근거: 해당 기능 이용 시 필수, 서비스 계약의 이행
  • 보유기간: 회원 탈퇴 시 해당 계정의 로컬 자료를 삭제합니다. 로그아웃하면 세션을 삭제하고 계정별 자료와 동기화 대기열은 기기에 보관하며, 같은 서비스 계정으로 다시 로그인해야 접근할 수 있습니다. 앱 삭제 시에는 OS 정책에 따라 삭제됩니다

6) 결제

  • 처리 목적: 그룹 슬롯·그룹별 공간 확장 구매 검증·복원·환불·부정 결제 방지
  • 처리 항목: 앱스토어 구분, 상품 ID, 거래 ID, 구매 토큰 또는 영수증 검증값, 구매·환불·취소 상태와 일시
  • 필수 여부 및 법적 근거: 구매 시 필수, 계약의 이행 및 법적 의무 준수
  • 보유기간: 구매 권한 제공·확인에 필요한 기록은 계정과 해당 권한이 유지되는 동안 보관합니다. 탈퇴하면 계정 연결을 해제하고 법정 보관 대상 거래·결제 기록만 거래일부터 5년 동안 분리 보관한 뒤 파기합니다. 소비자 불만·분쟁 기록은 3년 동안 보관합니다

7) 서비스 운영

  • 처리 목적: 장애 대응, 보안, 부정 이용 방지
  • 처리 항목: IP 주소, 접속·오류 로그, 기기·OS·앱 버전, 요청 일시
  • 법적 근거: 정당한 이익 또는 법적 의무
  • 보유기간: 오류·보안 로그 최대 90일. 법령상 별도 보관이 필요한 경우 해당 기간

8) 서비스 분석

  • 처리 목적: 기능 이용 현황, 품질·리텐션 개선
  • 처리 항목: 비식별 처리된 이용자 키, 국가, 언어, 플랫폼, 앱 버전, 로그인 수단, 기능 이용 기록
  • 법적 근거: 정당한 이익. 동의가 필요한 정보는 이용자 동의
  • 보유기간: 별도의 분석 도구를 두지 않고 서비스 운영 기록으로 산출하므로, 각 원본 항목의 보유기간을 따릅니다

9) 광고

  • 처리 목적: 전면광고 표시, 성과 측정, 부정 광고 방지, 광고 동의 상태 기록
  • 처리 항목: 광고 노출·클릭 이벤트, 기기·앱 정보, IP 주소, 광고 식별자(이용자가 허용하고 기기 설정이 허용하는 범위), 광고 동의 기록(앱 추적 허용·광고 동의 상태, 맞춤형 광고 허용 여부, 기기 플랫폼, 기록 일시)
  • 필수 여부 및 법적 근거: 맞춤형 광고와 광고 식별자는 선택, 이용자 동의 및 기기 설정. 비맞춤형 광고 표시와 부정 광고 방지에 필요한 기기·앱 정보와 IP 주소는 무료 서비스 제공을 위한 정당한 이익. 광고 동의 기록은 동의 사실의 증빙을 위한 법적 의무 준수
  • 보유기간: 광고 노출·클릭 이벤트, 기기·앱 정보, IP 주소, 광고 식별자는 운영자가 저장하지 않고 Google이 처리하며 Google의 보유기간을 따릅니다. 광고 동의 기록은 기록일로부터 13개월 또는 회원 탈퇴 시까지 중 먼저 도래하는 때까지 보관하며, 동의를 철회해도 철회 전 동의의 증빙을 위해 이 기간 동안 보관합니다

10) 고객 문의

  • 처리 목적: 문의 접수, 답변 발송, 반복 문의·스팸 차단
  • 처리 항목: 답변 받을 이메일 주소, 문의 내용, 앱 버전, 운영체제 종류(iOS·Android), 계정 식별자(로그인한 경우), 접속 IP를 일방향 암호화한 값
  • 필수 여부 및 법적 근거: 문의 시 필수, 이용자 동의 및 서비스 계약의 이행
  • 보유기간: 접수일로부터 1년. 로그인 상태에서 남긴 문의는 회원 탈퇴 시 즉시 파기

11) 권리 침해 문의

  • 별도 다른 회원 콘텐츠 신고 기능은 제공하지 않습니다. 고객지원으로 접수한 권리 침해 문의는 10) 고객 문의와 관련 법령에 따라 처리합니다.

12) 탈퇴 사유

  • 처리 목적: 탈퇴 사유 통계를 통한 서비스 개선
  • 처리 항목: 이용자가 선택한 탈퇴 사유, 이용자가 직접 입력한 상세 사유(선택, 50자 이내), 기록 일시
  • 필수 여부 및 법적 근거: 사유 선택은 탈퇴 시 필수, 상세 입력은 선택. 서비스 개선을 위한 정당한 이익
  • 보유기간: 계정 식별자를 함께 저장하지 않아 탈퇴한 이용자를 알아볼 수 없는 형태로 보관하며, 통계 목적이 끝나면 파기합니다

운영자는 사진이나 콘텐츠를 외부 AI 추론 서비스에 전송하지 않습니다. 결제 카드번호와 계좌정보는 Apple App Store 또는 Google Play가 직접 처리하며 운영자는 이를 수집하지 않습니다.

2. 개인정보의 수집 방법

  • 화면에 제공되는 Apple 등 소셜 로그인 과정에서 이용자가 허용한 정보를 제공받습니다.
  • 이용자가 앱에 직접 입력하거나 사진·콘텐츠를 선택해 등록할 때 수집합니다.
  • 앱 이용 과정에서 서비스 로그, 분석 이벤트, 광고 이벤트가 자동 생성될 수 있습니다.
  • Apple App Store 또는 Google Play에서 결제 검증에 필요한 거래 정보를 제공받습니다.

로그인 제공자가 선택 정보를 추가로 제공하더라도 테이크마이머니가 필요로 하지 않는 정보는 저장하지 않습니다.

3. 사진과 이미지의 처리

1. 이용자가 촬영하거나 선택한 원본 사진은 기기의 임시 저장공간에서 처리합니다.

2. 배경 제거는 iOS Vision 또는 Android ML Kit 등 이용자 기기의 기능으로 수행합니다.

3. 원본 사진은 외부 AI API나 프로덕션 이미지 추론 서버로 전송하지 않으며, 모델 학습에도 사용하지 않습니다.

4. 처리 성공 또는 이용자 취소 후 촬영 원본 임시파일을 삭제합니다. 실패한 촬영 사진은 앱 실행 중 재시도를 위해 최대 2분 동안 기기에만 임시 보관하며, 재시도 취소·로그아웃·만료 시 삭제합니다. 앱이 촬영 원본을 사진 보관함에 자동 저장하지 않습니다.

5. 이용자가 저장한 스티커 결과물만 서버에 백업합니다. 결과물은 계정별 기기 저장소에도 보관합니다.

6. 결과물 저장 전 EXIF와 위치 메타데이터를 제거합니다.

7. Android ML Kit은 입력 사진과 생성 이미지를 Google 서버에 전송하지 않고 기기에서 처리합니다. 최초 모델 다운로드와 모델·호환성 업데이트에는 네트워크 연결이 필요할 수 있습니다. Google은 SDK 진단·유지보수·사용 분석을 위해 기기 제조사·모델·OS·하드웨어 가속기 정보, 앱 패키지·버전, 기기 또는 설치 식별자, 처리 시간, 이미지 형식·해상도와 입력·출력 크기, 기능 버전, 모델 다운로드·호출·오류 코드 등 성능·사용 지표를 처리합니다. 원본 이미지 내용과 이 지표는 구분됩니다. 자세한 내용은 ML Kit 개인정보 안내와 Android 데이터 공개 안내를 따릅니다.

이용자가 OS 공유 기능을 실행하면 선택한 외부 앱으로 결과물이 전달됩니다. 이후 처리는 해당 앱 운영자의 개인정보 처리방침을 따릅니다.

4. 다른 이용자에게 공개되는 정보

개인 그룹과 콘텐츠는 해당 계정 본인에게만 표시되며 다른 회원에게 공개하지 않습니다. 이용자가 OS 공유 기능으로 외부 앱과 대상을 직접 선택하면 선택한 결과 이미지가 전달됩니다. 외부에 저장된 사본은 서비스에서 회수할 수 없습니다.

회원 탈퇴 시 프로필·그룹·콘텐츠·기기 로컬 자료와 로그인 연결 정보를 파기합니다. Apple 로그인 계정은 Apple 연결 해제 절차도 수행합니다.

5. 개인정보의 제3자 제공

운영자는 원칙적으로 개인정보를 제3자에게 제공하지 않습니다. 다음 경우에만 예외적으로 제공합니다.

  • 이용자가 사전에 동의한 경우
  • 법률에 특별한 규정이 있거나 법령상 의무를 준수하기 위해 불가피한 경우
  • 이용자가 OS 공유 기능을 통해 직접 전달 대상을 선택한 경우

향후 개인정보를 정기적으로 제3자에게 제공하게 되면 제공받는 자, 목적, 항목, 보유기간, 동의 거부권과 불이익을 사전에 고지하고 필요한 동의를 받습니다.

6. 개인정보 처리업무의 위탁

원활한 서비스 제공을 위해 다음 업무를 외부에 위탁합니다.

1) Supabase Pte. Ltd.

  • 위탁 업무: 회원 인증, 데이터베이스, 실시간 동기화, 결과 이미지 저장, 서버 기능 운영
  • 처리 항목: 계정·동의 기록, 프로필, 개인 그룹, 결과 콘텐츠, 문의 기록, 광고 동의 기록, 결제 원장, 접속 기록

2) Sentry(Functional Software, Inc.)

  • 위탁 업무: 앱 오류·성능 진단

11. 자동 수집 장치와 맞춤형 광고

서비스 운영 과정에서 SDK가 IP 주소, 기기·OS·앱 정보, 접속·오류 로그, 이용 이벤트를 자동 수집할 수 있습니다. 이러한 정보는 서비스 보안, 장애 대응, 이용 분석에 사용됩니다.

테이크마이머니는 스티커 만들기의 완료 버튼을 눌렀을 때 결과를 저장하기 전에 Google AdMob 전면광고를 표시할 수 있습니다. AdMob은 광고 제공·분석·부정 이용 방지를 위해 앱 실행·탭·광고 상호작용, 기기·앱 정보, 진단 정보와 기기·계정 식별자, IP 주소 및 IP로 추정한 대략적 위치를 처리할 수 있습니다. 정밀 위치 권한을 요청하는 것은 아닙니다. Google 광고 SDK 데이터 안내를 참고할 수 있습니다.

  • 광고의 맞춤형(개인화) 여부는 이용자의 동의 상태를 따릅니다. 동의 양식이 표시되는 지역에서는 이용자가 그 양식에서 직접 선택하며, 동의가 없으면 SDK 동의 상태에 따라 비맞춤형·제한적 광고가 표시되거나 광고 요청을 하지 않습니다.
  • iOS에서는 광고 SDK를 시작하기 전에 앱 추적 투명성(ATT) 권한을 요청할 수 있습니다. 허용하면 광고 식별자(IDFA)를 맞춤형 광고 선택과 성과 측정에 사용하고, 허용하지 않으면 IDFA에 접근하지 않습니다. 실제 광고 요청과 노출은 SDK 동의 상태, 광고 준비 상태와 네트워크 등에 따라 달라집니다.
  • ATT 권한은 언제든 설정 > 개인정보 보호 및 보안 > 추적에서 변경할 수 있습니다. 허용을 취소하면 그 이후의 광고는 비맞춤형으로 표시됩니다.
  • Android에서는 기기의 광고 개인정보 보호 설정을 따릅니다.
  • 맞춤형 여부와 무관하게 Google은 부정 클릭 방지, 노출 집계, 동일 광고의 반복 노출 방지를 위해 기기 정보를 사용합니다.
  • 이용자는 기기 설정에서 광고 식별자를 재설정하거나 사용을 제한할 수 있습니다. iOS는 설정 > 개인정보 보호 및 보안 > 추적, Android는 설정 > 개인정보 보호 > 광고입니다.
  • 유럽경제지역·영국·스위스 이용자에게는 Google 사용자 메시지 플랫폼(UMP)의 동의 양식을 표시하며, 이용자는 해당 양식에서 동의를 변경하거나 철회할 수 있습니다.
  • 광고 표시 자체를 끄는 설정은 제공하지 않습니다. 광고는 테이크마이머니를 무료로 제공하기 위한 것입니다.
